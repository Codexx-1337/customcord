# ⚡ Customcord

**Customcord** — ультра-быстрый, легковесный и нативный клиент Discord для Windows, написанный на **Rust**.
Разработан как эффективная альтернатива тяжелому официальному клиенту на Electron: потребляет в разы меньше оперативной памяти, мгновенно запускается и включает встроенный **Vencord**, глобальную рацию (Push-to-Talk) и снятые ограничения качества стрима.

---

## 🚀 Ключевые возможности

- ⚡ **Минимальное потребление памяти**: нативный Rust-рантайм ядра (~2–4 МБ) и оптимизированный Chromium WebView2.
- 🧩 **Встроенный Vencord**: предустановлен и активируется автоматически без необходимости ставить сторонние патчеры или Node.js.
- 🎙️ **Аутентичная глобальная рация (Push-to-Talk)**:
  - Работает поверх всех окон и любых полноэкранных игр в Windows.
  - Мгновенная активация микрофона (0 мс задержки).
  - Оригинальные звуки Discord (`ptt_start` / `ptt_stop`).
  - Синхронизация бинда клавиши (CapsLock, боковые кнопки мыши и любые клавиши) прямо из настроек Discord.
- 🖥️ **Снятие лимитов стрима экрана**:
  - Разрешение **480p–2160p** и частота **15–120 FPS** выбираются в пикере Vencord.
  - Битрейт подстраивается под разрешение и FPS (до **50 Мбит/с**), низкие лимиты Chromium/Discord (`x-google-max-bitrate`, `b=AS`/`b=TIAS`) убираются.
  - Encoder просят сохранять разрешение (`maintain-resolution`) для текста и десктопа.
  - Аппаратное кодирование WebRTC отключено по умолчанию — на части GPU/драйверов оно застревает на низком битрейте и даёт пиксельную картинку. Включить обратно: `set CUSTOMCORD_HW_ENCODE=1`.
  - Реальный битрейт, разрешение, FPS и причина ограничения пишутся в `debug.log` с префиксом `[STREAM]`.
  - Автоматическое скрытие желтой рамки и панели захвата экрана Windows/Chromium.
- 🔍 **Слайдер «Уровень масштабирования» (Zoom Level)**:
  - Встроенный в раздел «Специальные возможности» и «Внешний вид» слайдер масштаба от 50% до 200% с шагом в 15%.
- 🪟 **Безрамочный нативный интерфейс**:
  - Полная поддержка темной темы, перемещения окна за верхнюю панель и стандартных кнопок управления окном (свернуть, развернуть, закрыть).
- 🛡️ **Встроенный обход блокировки Discord**:
  - Локальный SOCKS5-прокси с фрагментацией TLS ClientHello (приём GoodbyeDPI/Zapret) — обходит DPI-фильтрацию по SNI без VPN.
  - DNS через HTTPS (DoH) — защищает от подмены DNS-ответов провайдером.
  - Поддержка внешнего SOCKS5/HTTP-прокси — для случаев, когда Discord блокируют по IP-адресу.

## 🛡️ Обход блокировки Discord (Россия / Беларусь)

Обход включён по умолчанию и не требует установки VPN или сторонних программ.

### Как это работает

1. Customcord поднимает локальный SOCKS5-прокси на `127.0.0.1` и направляет в него весь трафик WebView2.
2. Первый TLS-пакет (`ClientHello`) отправляется на сервер Discord двумя частями с разрывом внутри имени домена. DPI провайдера не видит целый SNI (`discord.com`) и пропускает соединение.
3. Имена доменов резолвятся через DNS over HTTPS (Cloudflare/Google), поэтому подмена DNS не мешает подключению.

### Настройки в приложении

Откройте **Настройки пользователя → Внешний вид** и прокрутите до раздела **«Обход блокировки Discord»**:

- **Обход DPI (фрагментация TLS)** — главный переключатель.
- **DNS через HTTPS (DoH)** — выключите, если ваша сеть блокирует DoH-резолверы.
- **Внешний прокси** — укажите `socks5://host:port` или `http://host:port`, если провайдер блокирует Discord по IP-адресу.

Настройки сохраняются в `%APPDATA%\Customcord\bypass.json` и применяются к новым соединениям (для полного применения прокси перезапустите клиент).

### Если Discord вообще не открывается

Если страница Discord не загружается, настройте прокси без входа в аккаунт — одним из способов:

```bat
:: аргумент командной строки
customcord.exe --proxy socks5://127.0.0.1:1080

:: или переменная окружения
set CUSTOMCORD_UPSTREAM_PROXY=socks5://user:password@host:port
customcord.exe
```

Также можно отредактировать `%APPDATA%\Customcord\bypass.json` вручную:

```json
{
  "enabled": true,
  "doh": true,
  "upstream": "socks5://host:port"
}
```

Полезные флаги: `--no-bypass` — запуск без обхода, `--proxy=...` — прокси на один запуск.

### Ограничения

- Фрагментация обходит DPI по SNI, но **не обходит блокировку по IP-адресу**. В РФ с 2026 года Discord блокируется в том числе по IP — в этом случае нужен внешний прокси или полноценный VPN.
- Голосовые каналы Discord используют UDP и не проходят через SOCKS5-прокси браузера. Для голоса может потребоваться VPN (либо прокси с поддержкой UDP).
- Поддерживаются SOCKS5 (`socks5://`, `socks5h://`) и HTTP CONNECT (`http://`). HTTPS-прокси и протоколы VLESS/Shadowsocks не поддерживаются.

## 🖥️ Диагностика качества стрима

Customcord пишет `debug.log` рядом с `customcord.exe` (в той же папке) строки вида:

```
[IPC] log: [STREAM] stats 1920x1080@60 enc=1920x1080 bitrate=8120kbps target=8200kbps cap=11200kbps q=none encoder=OpenH264 degradation=maintain-resolution
```

- `q=bandwidth` — не хватает исходящего канала или UDP/порт заблокирован; поможет VPN/прокси с UDP.
- `q=encoder` — encoder не успевает; попробуйте меньшее разрешение/FPS.
- `q=none` и высокий `bitrate` — поток кодируется нормально, проблема на стороне зрителя или SFU.

Переменные окружения:

- `CUSTOMCORD_HW_ENCODE=1` — вернуть аппаратное кодирование (меньше нагрузка на CPU).
- `CUSTOMCORD_SW_DECODE=1` — отключить аппаратное декодирование входящих стримов (если пикселизируются чужие демки).

## 🛠️ Сборка из исходников


### Требования
1. Установленный [Rust](https://rustup.rs/) (версия 1.75 или новее).
2. Установленный Microsoft Edge WebView2 Runtime (предустановлен в Windows 10/11).

### Сборка:
```bash
# Клонировать репозиторий
git clone https://github.com/Codexx-1337/customcord.git
cd customcord

# Собрать релизную версию
cargo build --release
```

Готовый бинарный файл будет находиться по пути:
`target/release/customcord.exe`
